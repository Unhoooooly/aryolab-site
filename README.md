# aryolab-site

Public static site for Aryolab, served by GitHub Pages at https://aryolab.com.

- `/` — Aryolab home
- `/madar/privacy/` — Madar privacy policy (source of truth: `docs/privacy_policy.md` in madar_app — keep both in step)
- `/madar/delete-account/` — how to delete a Madar account

Plain HTML and CSS: no build step, no scripts, no analytics, no external requests.
Fonts: IBM Plex Sans Arabic, self-hosted under the SIL Open Font License (`assets/fonts/OFL.txt`).
